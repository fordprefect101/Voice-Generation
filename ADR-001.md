# ADR-001 — Fish Audio S2 is the English TTS backend

- **Date:** 2026-10-05
- **Status:** Accepted
- **Covers:** English voice generation in [[Voice Generation]]

## Context

The repo tried Maya1, Qwen3-TTS VoiceDesign, CosyVoice 3, MOSS-TTSD and Fish S2. Listening tests are the judge, and Fish S2 gave the result we wanted.

## Decision

English uses Fish S2. Each host's voice is designed once, frozen as a reference clip with its exact spoken text (`voices/refs/male_ref.wav`, `female_ref.wav`), and cloned for every line. Other English backends (CosyVoice, MOSS, Maya1) and their code were removed on branch `cleanup-fish-only` to keep the repo clean. Qwen3-TTS VoiceDesign is kept, for now, as the tool that designs the reference voices, in case new voices are needed.

## Alternatives

- **MOSS-TTSD, CosyVoice 3, Maya1:** not chosen after listening tests. Code removed.
- **Qwen3-TTS as the generator:** not used to speak lines, but kept to design the voices that Fish clones.

## Consequences

One English path to maintain and tune. Hindi follows the same pattern (voice designed with Indic Parler or IndicF5, then Fish), and Rumik-OSS-1 is a Hindi candidate to compare by ear. Revisit if Fish quality or licensing stops fitting.
